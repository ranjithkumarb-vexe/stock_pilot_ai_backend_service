# Backend task board

Legend: status ∈ `todo · in_progress · blocked · partial · done · deferred`. Priority from SPEC (P0 ship, P1 if time). `Dep` = must be `done` first.
Frontend tasks (FE-*, INT-*) are in the web repo's `docs/workflow/TASKS.md`. Cross-repo deps are written `FE:FE-03`.
**Update this file in the same change that completes a task.**

## Wave plan
| Wave | Tasks | Agents (parallel) |
|---|---|---|
| 1 Foundation | BE-01, BE-02, BE-03, BE-04 (+ FE-01..03) | database-engineer + backend-engineer (foundation) ‖ frontend-engineer |
